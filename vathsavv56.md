## Projects

### KernUI-v2 (also called "Kern" in his resume)

A refined UI component library built with React, TypeScript and Tailwind CSS, with light and dark mode support throughout.

- Designed and shipped a lightweight React component library in TypeScript, styled with Tailwind CSS
- Includes a file explorer, button, footer, and an "inspired-by" section, ready to drop into any project
- Uses strict typing and a modular, composable architecture so components stay consistent and easy to extend
- Deployed on Vercel with a live demo

**Stack:** React, TypeScript, Tailwind CSS, Vite, Motion
**Live demo:** https://kern-v2-alpha.vercel.app/

### API Client (PIA)

A Postman-like API client for testing REST APIs with request history, collections, and response inspection.

- Built a Postman-inspired HTTP client that runs entirely in the browser
- Uses a reverse proxy to bypass CORS errors so requests can be sent to any API
- Built with React, TypeScript, Tailwind CSS, and React Router
- Manages app state with Zustand and validates data with Zod
- Persists collections and request data using the local file system, so it works without a backend or account

**Stack:** Bun, React, TypeScript, Tailwind CSS, React Router, Zustand, Zod
**Live demo:** https://pia-beta.vercel.app/
**GitHub:** https://github.com/vathsavv56/pia

### React-loaders

A collection of clean, Apple-inspired loaders built with plain Tailwind CSS, using no extra dependencies.

**Stack:** React, TypeScript, Node.js, Tailwind CSS
